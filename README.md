Mini Golf 3D

Genre: 3D Sports / Casual

Core Idea:
The player controls a golf ball and aims to get it into the hole using as few strokes as possible while navigating obstacles.

Mechanics
Player controls direction and power to hit the ball
Third-person camera follows the ball
Ball interacts with the environment (walls, ramps, obstacles)

Win / Lose Conditions
Win: Ball reaches the hole
Lose (Planned): Too many strokes or time runs out

UI Plan
Title screen with start button
Gameplay UI showing stroke count
End screen displaying win result
